# AI Knowledge Assistant

A learning project focused on building Retrieval-Augmented Generation (RAG) systems using OpenAI embeddings and semantic search.

## Features

- OpenAI embeddings
- Semantic similarity search
- Retrieval-Augmented Generation (RAG)
- Persistent embedding storage
- Context-grounded responses
